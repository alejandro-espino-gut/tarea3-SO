## Descripción

En esta tarea se implementó una simulación de First-Come-First-Served y Priority Scheduling, ambos en el archivo `simuladorPlanProcesos.c`.

## Compilación y ejecución

Para compilar, debemos ubicarnos en el directorio raíz de la tarea y ejecutar el siguiente comando

```
gcc -o simulador simuladorPlanProcesos.c
``` 

Para ejecutar, debemos ejecutar el siguiente comando

```
./simulador < Procesos.txt
```
